How this site handles your data

A privacy lab should be able to explain its own website in a few lines. Here they are.

  • No cookies, analytics, ads or tracking scripts.

  • No third-party requests. Fonts and all other files are served from this site; nothing loads from Google or any social network.

  • No forms. If you email us, we use your message only to reply.

  • The site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security purposes; see GitHub's statement on Pages data collection.
